# 设计规范：Code Work 界面

> 界面改造与评审的单一事实来源，也可直接用于向 Stitch 描述界面。数值以 `apps/web/src/index.css` 的真实令牌为准（`:root`、`@variant dark`、`[data-app-sidebar]`、`html[data-theme-id]`）。主题文件与「设置 → 外观」优先于本文默认值：凡是令牌已经提供的值，组件里不要再写死。

## 1. 视觉基调与气质

一间安静、仪器感的工位：干活的地方密集（时间线、diff、终端、文件树），其余地方克制。表面靠明度分层，而不是靠阴影堆叠。整体像一盏照得很准的夜间工作灯：亮色模式是中性的 zinc，暗色模式是真正的中性黑，只有一个蓝色动作色，且只出现在用户能操作的地方。

- **密度**：7 / 10，偏驾驶舱。28px（`h-7`）是默认控件高度；只有主输入框和输入区用 32–36px。
- **错落度**：3 / 10，可预期、对称。这是工具而不是落地页：对齐与节奏优先于错落。
- **动效**：4 / 10，流畅 CSS。短促、只走合成器的过渡；指示器按占空比循环；没有装饰性动画。

## 2. 配色与角色

亮色（`:root`）

- **画布锌白**（`--color-zinc-25`，oklch 99.2% 0 0）— 应用背景（`--background`）
- **纯表面**（#FFFFFF，`--card` / `--popover`）— 卡片、弹层、选中的侧边栏行
- **侧栏薄雾**（`--color-zinc-50`）— 导航列、次级与弱化填充
- **悬停水洗**（`--color-zinc-100`，`--accent`）— hover 与按下填充；从不当作品牌色
- **墨锌**（`--color-zinc-800`）— 主文字
- **哑钢**（`--color-zinc-500`）— 次级文字、元信息、占位符、弱化图标
- **发丝线**（`--color-zinc-200`，`--border`）— 1px 结构线；输入框用 `--color-zinc-300`

暗色（`@variant dark`）

- **中性黑**（`--color-neutral-950`）— 画布；表面在它之上混入 3%（卡片）与 6%（弹层）白来抬升
- **抬升水洗**（白色 4%）— 次级、弱化与强调填充
- **暗色发丝线**（白色 6%）— 边框；输入框白色 8%
- **柔白**（`--color-neutral-100`）— 主文字

动作色

- **Workbench Blue**（`--primary`，亮色 oklch(0.488 0.18 264) / `#2855c4`，暗色 oklch(0.571 0.19 264) / `#3b6ee6`）— 全站唯一强调色：发送按钮、主操作、焦点环（`--ring`）、滑块填充、更新徽标。不要再引入第二种强调色。色度刻意压在 sRGB 饱和度 80% 以下：更高的色度挨着 zinc 中性面会发紫，读起来像「AI 蓝紫」而不是工作台蓝。白字对比度为亮色 6.59:1、暗色 4.61:1，两种模式都满足 WCAG AA。`themePalette.ts`、桌面预览默认值与 `Annotation.css` 中的同名值必须与此保持一致。

状态色（与主题强调色无关）

- **错误** red-500 / 文字 red-700（暗色 red-400），表面 8%（暗色 16%）
- **警告** amber-500 / 文字 amber-700（暗色 amber-400）
- **成功** emerald-500 / 文字 emerald-700（暗色 emerald-400）
- **信息** blue-500 / 文字 blue-700（暗色 blue-400）

状态色只以文字、1px 描边或淡染表面的形式出现，不要做大面积实心填充。

## 3. 字体规则

- **界面字**：平台原生字体栈（`-apple-system, BlinkMacSystemFont, "Segoe UI", system-ui, sans-serif`）。刻意用原生：这是桌面工具，且用户可在「设置 → 外观」覆盖（`--font-sans`）。不要为外壳打包 Web 字体。
- **输入框**：`--font-composer`，回落到界面字体；字号 `--font-size-prompt`。
- **等宽字**：`"SF Mono", "SFMono-Regular", Menlo, Consolas, "Liberation Mono", monospace`（`--font-mono`），用于代码、diff、终端、路径、模型 ID、token 计数、时间戳与任何数字列。计数类使用等宽数字（tabular）。
- **字阶**：11px（微标签、kbd）、12px（`text-xs`，密集行与元信息）、14px（`text-sm`，正文字号）、16px 仅用于触屏输入以避免移动端缩放。层级靠字重（400 / 500 / 600）和颜色建立，不靠字号跳跃。
- **行宽**：长段助手正文控制在约 72ch；代码块可以更宽。
- **禁止**：应用外壳出现衬线字体；加字距的整段大写；用加粗做装饰。

## 4. 组件规范

- **按钮**：扁平填充，无发光。主按钮用 Workbench Blue；次按钮为描边或 ghost 配 Hover Wash。按下时下移 1px；禁用降到 64% 不透明度。默认高 28px，图标 14px。
- **输入 / 选择 / 多行 / 组合框**：`rounded-lg`（10px），1px 输入边框，标签在上、错误在下，聚焦 = `--ring` 边框加 3px 24% 透明环。不用浮动标签。
- **卡片**：`rounded-2xl`（18px），1px 细线加既有的内顶部高光（`before:` 1px 线）。阴影保持 `shadow-xs/5`。密集列表中改用细线分隔，不用卡片。
- **弹层 / 菜单 / 提示**：菜单 `rounded-lg`、提示 `rounded-md`，玻璃表面（`dropdown-glass`），进场从 98% 缩放到 100% 并淡入。
- **代码块**：`rounded-[var(--radius)]`，亮色下 1px 细线边框，暗色下无边框 `input/32` 填充，等宽小标题 11px。
- **加载态**：与最终布局尺寸一致的骨架微光（`--animate-skeleton`）；状态点用 `status-pulse`。内容加载不用圆形转圈。
- **空状态**：图标块（`size-9`、`rounded-md`、细线）加一句说明此处将出现什么，以及一个操作。不要只写「暂无数据」。

## 5. 布局原则

- 固定分区：侧边栏、时间线、可选侧面板（diff / 文件 / 浏览器）。分区布局用 CSS Grid；flex 只用在行内。
- 间距遵循 4px 栅格。行间距 8px，区块间距 16px，面板内边距 12–16px。
- 圆角族由 `--radius`（0.625rem）派生：sm 6px、md 8px、lg 10px、xl 14px、2xl 18px。嵌套元素用父级圆角减 1px（已编码为 `calc(var(--radius-*) - 1px)`）。
- 640px 以下收为单列；触屏点击区用 `pointer-coarse:after` 撑到 44px，而不是把控件本身放大。

## 6. 动效与交互

- 只对 `transform` 与 `opacity` 做动画；热路径（时间线）上不要对宽度、高度或阴影做动画。
- **时长只有两档**：150ms 用于 hover / press 等微反馈，200ms 用于弹层、面板与内容过渡；面板上限 240ms。进场 ease-out，退场 ease-in。指示器循环（`duration-2000`）与即时态（`duration-0`）不受此限制。
- 指示器循环按占空比设计（`status-pulse` 2s、`ghost-pulse` 2.4s），让合成器大部分时间空闲。
- 尊重 `prefers-reduced-motion` 与既有的 `.no-transitions` 开关。

## 7. 禁止项

- 用 emoji 当界面图标（消息正文里的 emoji 不受此限）
- 亮色面上用纯黑 #000 文字；霓虹发光；渐变文字
- 引入第二种强调色，或让主操作偏紫
- 用状态色做大面积实心填充
- 三张等宽推广卡片、居中营销大标题、「向下滚动探索」之类的提示
- 营销腔文案（「赋能」「无缝」「释放」「下一代」）与虚假的整数指标
- 令牌已存在时仍在组件里写死十六进制色值
- 使用远程占位图（Unsplash）；用本地 SVG 或首字母头像
