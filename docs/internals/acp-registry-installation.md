# ACP 官方目录与二进制安装

核对日期：2026-09-30。目录、下载和会话运行分开维护；安装成功不代表 Agent 已登录、模型可用或工具验收完成。

## 模块边界

- `packages/contracts/src/acpRegistry.ts` 定义目录、分发、安装输入/结果与明确错误；`rpc.ts` 注册方法。客户端只提交 `entryId`，不能指定下载地址或 SHA-256。
- `AcpRegistryCatalog.ts` 解析官方目录，校验当前 OS/CPU、相对启动路径、安全参数、HTTPS 归档与完整 SHA-256；`manual-agent-catalog.ts` 补充已核对的手工入口。在线失败显式返回错误、来源和离线快照日期。
- `AcpRegistryBinaryInstall.ts` 实现下载、限流大小、SHA-256、解包和发布。复用 CodeOSS 的系统 tar 解析和进程执行，无新依赖或专用 Agent Adapter。
- `server.installAcpRegistryBinary` 在服务端重新按 ID 查询目录，要求当前环境的操作权限；共享客户端命令按环境和 ID 合并并发请求。Web/Mobile 保存返回命令，后续仍经原 Provider 实例和通用 ACP 生命周期启动。

## 安装与失败行为

安装根目录为环境的 `<baseDir>/acp-agents`，每项安装路径包含 ID、版本、平台与归档哈希前缀。只接受绝对安装根目录；解析路径与真实目录均必须保持在根目录内，版本目录不得越出条目目录。临时目录使用独立 UUID，只清理本次创建的临时目录。

先流式下载，最多 512 MiB，下载等待上限 10 分钟并响应调用方取消。SHA-256 不符时明确失败，不解包、不发布。支持 ZIP、tar.gz/tgz/tar.bz2/tar.xz 和目录可识别的原始二进制；Linux ZIP 使用 unzip，Windows/macOS 使用系统 bsdtar。启动文件必须是解包目录内的真实普通文件；非 Windows 设置可执行权限。

发布使用目录 rename，不先删除目标。两个下载并发到达时各自拥有临时目录，先完成者发布，后完成者核对已安装标记和启动文件后复用。损坏或无法确认的同名缓存保留原内容并返回 `extract-failed`，不自动清空目录。可保留现场并选择不同版本；人工处理损坏安装时须先核对具体安装目录，不能删除整个环境数据目录。

`codework-install.json` 保存条目、版本、平台、归档 URL、SHA-256 和启动路径，仅用于安装识别；复用不重新下载。它不验证登录、模型余额，也不是对用户后来改动启动文件的完整性认证。

## 客户端回填

Web 与 Mobile 目录按所选环境调用同一安装 RPC。组件用同步请求标记阻止渲染前的重复点击，用当前选择的生命周期标记验证结果归属；切换条目、修改命令或卸载后，迟到成功/失败均不能回填旧表单。改变选择会撤销回填资格，当前请求仍保持下载反馈直到结束；关闭页面不承诺撤销服务端已经开始的下载。环境切换以环境 ID 重建目录组件。

Mobile 将完整选中条目传回目录，已下载命令不从原始目录的 null 字段读取。Web 合并最新配置草稿后保存目录默认值，保留其它字段。两端复用既有实例保存入口、公开环境参数与明确空认证语义；图标加载失败使用文字占位。目录和配置文案支持中、英、日语。

Web 内置 41 个目录 SVG，来源为 2026-09-30 的官方 ACP Registry CDN，与目录快照同源；`acpAgentIcons.ts` 只为实际打包的 ID 使用本地路径，新增在线条目使用目录提供的 HTTPS 图标。来源许可证保留在 `apps/server/src/provider/acp/registry-snapshot.LICENSE`。Mobile 使用目录图标并保留加载失败占位。

## 验证证据

`AcpRegistryBinaryInstall.test.ts` 覆盖 raw 下载、哈希拒绝、缓存复用、损坏缓存保留、路径越界、两个下载同时发布，以及真实 tar.gz 嵌套启动路径。目录、Web picker/图标和 Mobile 配置逻辑另有定向回归；逻辑测试不替代浏览器或原生设备验证。

2026-09-30 用仓库外独立根目录执行了生产安装函数：Amp ACP v0.9.0 的 Windows x86_64 ZIP 为 38,461,044 字节，SHA-256 为 `3b2c3d14d703fcf9572da9733e4941703a7744bd37ec4aaa75421d6002c0157b`，与固定目录及 GitHub Release digest 一致。解包后 `amp-acp.exe` 为 99,161,088 字节；第二次安装复用同一路径，下载计数仍为 1，文件 mtime 未变。`--help` 退出 0 但无输出，不能据此声称 CLI 提供帮助或已验证协议。

首次探针使用较短的 120 秒调用方期限，真实下载被中断并返回 `download-failed`，临时目录已清理。按产品 10 分钟上限重新执行同一官方 URL 后成功，未切换来源或关闭校验。没有使用宿主凭据；没有在此步骤验证认证、文本、工具、余额、真实设备或远程连接。
