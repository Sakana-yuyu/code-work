## Web 长流交互的验收边界

- 2026-09-25 在本机隔离开发环境、1280×720 视口中，预置 1202 条交错的推理与工具活动，另运行一次真实 Codex `pwd` 回合。客户端可见流式正文、工具开始与完成、失败详情及历史折叠；上滚和回到最新正文未出现白屏或布局溢出。
- 临时 `requestAnimationFrame` 采样器只记录页面可见时相邻帧的间隔，保留最近 120 帧；对时间线连续执行四组上滚 20 页、下滚 20 页。稳定空闲窗口的 p95 为 16.8 ms、最大 16.9 ms、超过 50 ms 为 0；连续滚动后的窗口 p95 为 16.8 ms、最大 66.7 ms、超过 50 ms 为 1。展开旧思考摘要后内容仍可见。采样器在验收后已移除。
- 开发构建首次载入的前 50 帧另测得 p95 133.4 ms、最大 216.7 ms、超过 50 ms 为 8。此项不能与稳定交互混为一谈；Web 以外设备、生产构建冷启动和独立桌面外壳仍需单独验证。

## 当前产品边界

- 一个线程使用同一套活动合同来显示其所选 Agent 的正文和工具事件；“共用界面”指一致的客户端时间线与状态语义，不表示把多个独立线程的内容混成一条无来源的全局流。
- 供应商选择分为 Agent 运行器、BYOK 来源实例、该实例中的模型通道。当前路由只公布所选来源和协议相容的模型；未找到来源时不得回退到原生模型。密钥及余额 Token 留在服务端密钥存储，客户端只收到脱敏标记。
- 余额看板的金额、单 Key 限额、订阅套餐窗口和 CLI 原生额度各有不同含义。供应商目录只能声明本服务端已实现的查询能力，不能照搬其他产品的模板标签。实际账号余额仍需用户自己的有效凭据和上游接口验证。
- 外部资料未提供可直接套用的 Code Work 帧率阈值。上述 Web 验收已记录长流、展开历史和滚动的可见状态及帧间隔；桌面独立外壳、手机实机、更多设备和生产冷启动仍需按各自环境复测。
