# 自定义背景与材质

桌面版和网页版可在「设置 → 外观 → 创建主题」中设置背景，或编辑已有的自定义主题。内置主题可先复制，再修改；原来的浅色、深色、跟随系统、颜色编辑和主题导入仍然可用。手机原生客户端暂不应用这些背景设置。

## 图片和视频

在「背景与材质」里选择整体背景、侧边栏或对话与内容区，然后选择本地图片，或输入图片 URL 并点击使用。整体背景还支持本地视频。

- 本地图片上限 50 MB，支持当前浏览器能够解码的 PNG、JPEG、WebP、GIF、AVIF、SVG、BMP 等图片，并尝试转换 HEIC/HEIF。导入后会转换为静态 WebP，长边最多 3840 像素；GIF 不保留动画。过大的像素尺寸或不支持的编码会提示错误，不会覆盖之前的背景。
- 本地视频上限 200 MB。推荐 MP4（H.264）或 WebM；MOV、MKV 等能否播放取决于内部编码和设备，扩展名并不保证兼容。不能播放时请先转换格式。
- URL 只用于图片，支持 HTTP/HTTPS。外部网站会收到图片请求及你的 IP；链接可能过期或被防盗链拦截，HTTPS 页面也可能拦截 HTTP 图片。不要分享含私人凭据的链接。
- 本地媒体保存在当前浏览器或桌面客户端的本地资源库，不会上传到模型供应商或环境服务器。更换浏览器、应用或站点地址不会自动迁移；清除站点数据会删除本地主题和媒体，重要配置请先导出。

视频默认静音。编辑器和侧边栏底部提供暂停、播放、声音开关及音量控制。切换视频或重新打开应用后不会自动恢复出声。视频会增加显卡占用和耗电；页面不可见时暂停，系统开启减少动态效果时默认暂停，可手动播放。

## 分区域调整

整体背景、侧边栏、对话与内容区、用户消息、助手消息、输入框、菜单与弹窗、代码块均可设置底色、渐变、不透明度、模糊、圆角、边框和阴影。未单独设置的区域保留当前主题，或继承整体材质。图片与视频还可调整填充方式、位置和遮罩强度。

拖动设置会实时预览；点击保存才会保留，取消恢复进入编辑器前的主题。「恢复此区域」只撤销当前区域的覆盖，不影响其他区域。过低的不透明度或遮罩会影响阅读，界面会给出提醒；编辑器始终保留可读底色。

设置区域底色或渐变时，编辑器会结合文字颜色和不透明度估算对比度。低于 4.5:1 时会提示调整底色，并提供「恢复此区域」入口；图片、视频和透出的背景内容仍需以实际阅读效果为准。

## 保存、备份与分享

如果本地保存失败，当前窗口会保留已经应用的外观，并提示尚未保存。点击提示中的「重试」会保存当前最新设置；重试成功前刷新或关闭窗口，可能丢失尚未保存的修改。

主题可以分别配置浅色和深色。刷新后会恢复已保存的选择及本地媒体。导出时有两种方式：

- **仅导出设置**：JSON 包含配色、材质和外链图片地址，但不包含本地图片或视频。
- **包含媒体的主题包**：ZIP 包含主题设置与引用的本地媒体，可通过「添加主题 → 导入含媒体的主题包」在其他客户端恢复。请先检查是否包含私人照片或视频；主题包总大小限制为 220 MB。

导入主题包会验证内容并分配新的资源标识，不会覆盖已有主题的媒体。取消导入或取消编辑会清理此次产生且未被已保存主题使用的资源；删除主题时也会清理不再被其他主题引用的媒体。
