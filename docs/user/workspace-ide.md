# IDE 工作区

在网页版或桌面版中打开项目对话，使用顶部「对话 / IDE」切换器进入 IDE。顶部空间不足时，切换器会收为显示当前模式的下拉菜单。模式选择会记住；切回对话模式后恢复原有项目侧栏和对话布局。

点击切换模式时，工作区会短暂淡入，保留编辑器和对话草稿。键盘操作或启用系统「减少动态效果」时即时切换。

当前草稿尚未关联有效项目时，IDE 显示「打开项目」页，直接列出项目名称、路径和所属环境。选择项目后打开对应编辑区，并保留已输入的草稿内容；也可添加项目或进入连接设置。环境加载中和连接不可用时会显示对应状态。

IDE 使用完整的 Code-OSS 工作台。首次打开时，当前环境会下载并校验适合本机平台的运行包；准备状态显示在编辑区域，失败后可点击「重新连接 IDE」重试。运行包与插件安装在 Code Work 自己的数据目录，不读取或覆盖已有 VS Code、Cursor 的设置和扩展。

IDE 共用 Code Work 顶部栏，编辑区直接衔接文件树和标签页；原生菜单保留在左侧活动栏。工作台名称、空编辑区标志及页面图标使用 Code Work 品牌。右侧对话使用紧凑标题和底部输入框。

底部终端、问题、输出和调试面板按需展开；没有打开面板时，编辑器会占满剩余高度，不会保留空白面板区域。

IDE 内置界面跟随「设置 → 通用 → 语言」，与对话模式一致，支持简体中文、英文和日文；选择「跟随系统」时使用同样的系统语言结果。菜单、资源管理器、搜索、源代码管理、终端面板和扩展管理都使用该语言。工作台启动后修改语言，顶部会提示先保存文件，再点击「重新加载」应用。第三方扩展的界面语言取决于其提供的翻译，终端中的程序输出使用程序自身的语言设置。

IDE 与对话模式共用界面配色。在 Code Work 设置中选择或调整主题，IDE 的编辑区域背景、文件树、标签栏、面板和终端会一起更新；在 IDE 中确认选择颜色主题后，顶部栏、对话区和设置页也会同步，并将配色保存到 Code Work 主题库。IDE 主题选择器中的临时预览不会保存到对话模式，取消后仍使用原主题。

在 Code Work 主题编辑器设置的全局背景图片、视频、渐变以及内容区背景也会延伸到 IDE。文件树使用侧栏背景，编辑区和终端共用内容背景；区域背景色、透明度和模糊沿用主题设置。视频继续使用同一播放器，IDE 顶部保留播放、暂停、静音和音量控制；启用「减少动态效果」或页面进入后台时遵循原有暂停规则。透明度仅作用于背景，文字、光标和选区不会一起变淡。

切换模式或刷新页面后保留主题选择；取消主题编辑预览或切回没有背景装饰的主题时，恢复对应的背景与工作台底色。如果原 IDE 主题扩展不可用，仍会使用保存的界面配色。系统深浅模式由 Code Work 的外观设置统一控制。背景装饰由 Code Work 主题设置管理；IDE 主题插件只同步界面配色，文件图标、代码高亮规则和其他扩展行为保持各自原有设置。

## 编辑与项目工具

工作台提供原生文件树、标签页和编辑器分组、全文搜索、源代码管理、集成终端、运行和调试、任务、问题与输出面板、设置、快捷键和主题。文件读写、Git 和终端在当前项目所属环境执行；远程项目使用远程环境的工具和运行时。

Git 使用 Code-OSS 自带的 Git 扩展，环境需要安装 Git。语言补全、调试和测试功能由内置或安装的语言扩展提供，相应 SDK、编译器、调试器需要在项目环境中可用。VS Code 的工作区信任、保存提示和扩展权限行为保留。

顶部「工作区」菜单可打开文件、搜索、Git、终端、扩展管理；「项目与对话」用于选择 Code Work 中的其他项目或历史对话。AI 消息中的文件定位会在原生编辑器中打开对应文件和行。IDE 自己的「打开文件夹」只改变工作台窗口，Code Work 对话所属项目仍由顶部的项目选择确定。

## Code Work 对话

右侧保留当前 Code Work 对话，顶部右侧按钮可收起或展开。拖动对话区左侧分隔线可缩小或扩大宽度，调整结果会记住；也可聚焦分隔线后用左右方向键调整，Home / End 移至最小 / 最大宽度。切换布局时保留对话草稿、工作台和终端窗口；切换到另一个项目则打开对应工作区。原生工作台关闭内置 AI 功能，并禁用默认 Copilot 扩展。

在原生编辑器中选中代码后，右侧对话输入框会自动出现一条「文件名 L起-L止」引用芯片，其中包含选中的内容和行号；继续拖动选区时芯片会实时更新为最新范围，而不是累积多条。芯片随草稿保留，只有点击发送才会交给 Agent；空选择不会加入草稿。

## 扩展

通过工作台左侧「扩展」或顶部「工作区 → VS Code 扩展」搜索、安装、禁用、卸载扩展。默认使用 Open VSX 扩展目录，也可通过扩展菜单的「从 VSIX 安装」安装有权使用的扩展包。编辑器主题、语言服务、格式化器、调试器和其他工作区扩展由原生扩展宿主加载。

插件兼容性取决于扩展声明的 VS Code API 版本、所需运行平台、原生依赖和许可条件。仅支持桌面本地 UI 宿主、依赖微软专有服务或限制发行版的插件，不保证在 Web 工作台中可用；安装 VSIX 不会自动消除这些限制。内置 AI 与默认 Copilot 不属于此集成。

## 环境与连接

当前运行包覆盖 Windows x64、Linux x64/arm64、macOS x64/arm64。其他架构会显示明确的不可用提示。首次下载需要能访问 GitHub，在线安装扩展需要能访问 Open VSX。远程使用建议通过 HTTPS，以便浏览器提供扩展 Webview、剪贴板等所需的平台能力。

工作台连接复用 Code Work 环境入口，只有具备操作权限的已登录会话可以启动。撤销环境访问后，工作台连接也会失效。退出 Code Work 环境服务会停止其启动的 IDE、扩展宿主和终端进程；文件、设置和安装的扩展保留。

通过 SSH 添加环境需要使用桌面版的「设置 → 连接设备」；网页版通过远程链接与配对码连接已运行的 Code Work 环境。IDE 使用所选项目所属的环境，浏览器所在电脑不一定是文件、Git 和终端实际运行的主机。

窄窗口或对话分屏使用原有对话布局，并保留 IDE 偏好。React Native 手机客户端继续使用移动端界面。
