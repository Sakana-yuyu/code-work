# 导入 CLI 历史会话

在左侧会话栏点击“导入 CLI 会话”，选择项目后，Code Work 会在该项目所在环境扫描 Codex 和 Claude Code 的会话文件。搜索并选择一条记录即可导入；导入后可像普通线程一样打开和搜索。再次选择同一条记录会打开已有线程，已有标题和消息不会被覆盖。

扫描与读取都在项目所在的服务端进行。会话列表不会传输原始日志路径，Code Work 也不会修改 CLI 的原始文件。只会列出日志中记录的工作目录与所选项目目录相同的会话。

如果该环境已经配置并安装相应 Provider，导入时会保存原生恢复游标；首次发送消息时由原 Provider 继续会话。未配置或不可用时，可先查看历史。配置好 Provider 后，在导入窗口再次选择该记录以启用续聊。是否能恢复仍取决于原 CLI 对该会话的支持和本机日志是否仍然存在。

单条日志超过 100 MiB 会拒绝导入。其余大型会话最多保留最近 1,000 条文本消息，总计不超过 2,000,000 个字符，每条最多 20,000 个字符；如果发生截取，导入后会明确提示。图片、工具调用和附件目前不作为历史消息导入。
