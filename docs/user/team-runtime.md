# 外部团队运行时

需要连接外部团队守护进程时，在「设置 → AI 团队」展开「高级：外部团队运行时」，然后新建或选择团队运行时。

填写运行时 ID、守护进程 ID、守护进程运行时 ID、基础 URL 及所需环境变量。配置有效后可点击「保存」；等待出现已保存提示后，修改才已保存到当前环境。保存失败时草稿会保留，可修正后重试。

编辑过程中，其他配置刷新和折叠高级区域不会覆盖草稿。切换运行时或离开设置时，系统会询问是否放弃未保存修改；选择取消可继续编辑。

如果同一运行时已被其他设备修改，保存会提示冲突，避免覆盖对方的配置。先记录需要保留的草稿内容，再点击「重新加载最新配置」，确认放弃当前草稿后重新编辑。

页面引导支持键盘操作。按 Esc 可关闭引导并保留当前设置页面或输入弹窗；输入类步骤需填写完成后点击「下一步」。
