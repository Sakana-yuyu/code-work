# 使用 ACP 会话中的模型、模式和命令

## 从目录安装和选择 Agent

在供应商设置中添加 ACP 智能体，进入连接配置后搜索目录。提供官方二进制的条目可点击“下载并安装”，由所选服务器环境下载并校验后填入启动命令；安装在服务器环境中完成。下载期间按钮显示处理状态，成功后显示“已选择”。失败时保留错误并允许重试，手工命令仍可填写。

窄屏中，安装或选择按钮会在空间不足时移到说明下方。可以滚动配置内容查看底部操作，也可通过键盘访问“返回”和“添加实例”。返回可检查命名步骤，关闭向导会放弃当前草稿；点击“添加实例”才保存连接。安装成功不代表账号认证或模型调用成功。

## 会话目录与控制

Agent 建立会话后，可以提供该会话支持的模型、模式、角色、权限选项和斜杠命令。聊天中的模型菜单会随会话更新；网页和手机使用同一份会话信息。CLI 默认模型表示由 Agent 决定模型，不表示已获得某个模型的使用权限。

打开模型菜单选择模型及 Agent 模式。模式名称用于显示，实际选择保持 Agent 提供的原始值。有完整 Agent 模式菜单时，使用该菜单选择模式。角色和权限选项也在模型菜单中显示；只有 Agent 提供这些选项时才可选择，默认角色可以是空值。

输入 `/` 查看当前 Agent 的命令。选择命令后按参数提示填写，再发送消息。Agent 撤回的命令、模式或模型不会继续作为该会话的可选项；其它 Agent 实例的目录不会混入当前会话。显式添加的自定义模型仍保留。

切换失败会显示错误，不能把菜单存在、认证方法返回成功或 CLI 安装成功当成模型可用。实际模型调用仍由 Agent 的账号、配置和上游服务决定。重新连接后，会话信息重新与 Agent 同步；没有提供会话目录的旧服务继续使用原有配置目录。
