# 在更多智能体会话中使用模型、模式和命令

## 添加与安装

在 **设置 → 供应商** 中点常用智能体卡片，或选择 **更多智能体** 后按产品名搜索。进入连接配置后，可安装的条目可点 **下载并安装**，由所选环境下载并校验后填入启动命令；需手工配置的条目请先按安装说明装好 CLI，再保存。

窄屏中，安装或选择按钮会在空间不足时移到说明下方。返回可检查命名步骤，关闭向导会放弃草稿；点 **添加实例** 才保存。安装成功不代表账号或模型已经可用。

已添加的实例可在配置页 **更换智能体**，从同一列表重新选择并回填启动命令与默认项。

## 会话中的模型、模式与命令

智能体建立会话后，可提供该会话支持的模型、模式、角色、权限选项和斜杠命令。聊天中的模型菜单会随会话更新；网页和手机使用同一份会话信息。「CLI 默认模型」表示由智能体决定模型，不表示已获得某个模型的使用权限。

打开模型菜单选择模型及 Agent 模式。模式名称用于显示，实际选择保持智能体提供的原始值。角色和权限选项也在模型菜单中显示；只有智能体提供这些选项时才可选择。

输入 `/` 查看当前智能体的命令。选择命令后按参数提示填写，再发送。智能体撤回的命令、模式或模型不会继续作为该会话的可选项；其它实例的选项不会混入当前会话。显式添加的自定义模型仍保留。

切换失败会显示错误，不能把菜单存在、登录成功或 CLI 已安装当成模型可用。实际调用仍由智能体账号、配置和上游服务决定。重新连接后，会话信息会重新同步。

## 取消后发送下一条消息

取消会立即结束当前回合显示和待定审批。下一条消息仍需等智能体确认上一回合结束；迟迟不确认时，会提示「新请求未发送，请重新连接会话」。重新连接并确认执行状态后再发送；取消不保证已执行的命令或文件操作被撤销。

CodeBuddy 在取消后可能短暂拒绝新请求。提示「取消保护窗口尚未结束」时，请稍后手动发送；应用不会自动重发消息或重复执行工具。
