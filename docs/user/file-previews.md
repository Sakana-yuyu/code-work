# 工作区文件预览

在对话右侧的文件面板中选择项目文件，可以查看文本、Markdown、HTML、图片以及 `.docx`、`.xlsx`、`.pptx` 文档。

Office 文件以只读方式展示：Word 显示段落文字，Excel 按工作表名称和行列位置显示单元格值，PowerPoint 按幻灯片显示文字。为保持预览流畅，Excel 表格只展示有限的行列并提示截断。图表、图片、动画和精确排版不会还原；需要核对最终外观时，请用文档编辑器打开原文件。

预览只在打开文件时读取，最多处理 12 MB 的 Office 文件。面板保持打开时，会定期检查文件是否保存了新版本并刷新内容；关闭面板后停止检查。右上角的刷新按钮可立即重试。文件损坏、过大或环境连接不可用时，面板会给出错误提示。

文件始终从项目所在环境读取，远程项目不要求把文件复制到当前电脑。访问使用 Code Work 现有的项目权限和短期文件链接。
