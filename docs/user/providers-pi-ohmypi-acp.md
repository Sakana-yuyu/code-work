# 使用 Pi / OhMyPi 与更多智能体

Code Work 支持三类可扩展供应商：**Pi** 与 **OhMyPi** 是只能用你自己的模型线路运行的 CLI 智能体；**更多智能体** 则把 Cline、Qwen Code、Copilot、Gemini 等常用 CLI 接到同一套「连接 / 启动命令 / 登录」设置里。三者都在 **设置 → 供应商** 中添加，默认关闭，需要在所选环境上安装对应 CLI。

## Pi 与 OhMyPi：完全运行在你的自定义模型服务上

Pi 和 OhMyPi 没有自己的登录或付费账号。Code Work 会为它们维护一份受管理的配置，里面**只**注册你的自定义模型服务作为模型来源，并且清空了其它模型服务的密钥环境变量——这两个 CLI 从构造上就无法使用别的凭据，也不会把你的渠道密钥带进它们自己的配置目录。

准备步骤：

1. 在 **设置 → 供应商** 添加一个 **自定义模型服务** 实例，并在其中配置模型通道。
2. 只有 **OpenAI 协议** 和 **Anthropic 协议** 的通道会被使用；Gemini 协议通道不在这两个供应商的可用范围内。
3. 安装对应的 CLI（`pi` 或 `omp`），然后在 **设置 → 供应商** 添加 Pi / OhMyPi 实例。

行为说明：

- 模型选择器里出现的模型就是你的模型通道；没有可用通道时，对话会直接报错提示先配置模型服务，不会悄悄借用其它凭据。
- 修改模型通道后，Pi / OhMyPi 会在当前运行的任务结束后自动使用新的通道配置。
- 图片附件（PNG / JPEG / WebP / GIF）会随消息一起发送。

### OhMyPi 的工具审批

OhMyPi 自带的 bash / 编辑 / 写入工具遵循对话的权限模式：

| 权限模式                 | OhMyPi 行为                            |
| ------------------------ | -------------------------------------- |
| Supervised               | 每个内置工具都先询问（Approve / Deny） |
| Auto-accept edits / Auto | 文件写入自动通过，命令等仍会询问       |
| Full access              | 全部自动通过                           |

审批会以对话内请求的形式出现，批准或拒绝后 agent 继续。也可以在实例设置中把 **原生工具审批模式** 固定为 询问 / 写入 / 全自动，覆盖随权限模式变化的默认行为。

### 限制 Pi 的内置工具

Pi 的内置工具没有审批协议，只做展示。如需限制它可用的工具，在实例的 **启动参数** 里填 CLI 原生参数，例如 `--tools read,grep` 只保留读取和搜索。

## 更多智能体：像添加 Codex 一样添加 Cline / Qwen 等

在 **设置 → 供应商 → 添加** 里，常用产品有独立入口（GitHub Copilot、Gemini CLI、Cline、Qwen Code）。点开后会进入与 Codex / ZCode 同类的连接配置：先确认启动命令与登录方式，再保存。其它 CLI 智能体走 **更多智能体**，按产品名搜索列表选择即可。Web、桌面与手机入口一致。

### 快速上手

1. 打开 **设置 → 供应商 → 添加**。
2. 点常用卡片（如 **Cline**、**Qwen Code**），或选 **更多智能体** 后按中文/英文产品名搜索。
3. 在列表里确认版本，需要时可 **下载并安装**；也可保留已有本机命令。
4. 在 **连接** 区选择：用官方 CLI 在所选环境登录，或改走共享网关。
5. 保存后，在实例卡里仍可 **更换智能体**、改登录方式，或在高级区编辑完整启动命令。

“CLI 默认模型”表示不覆盖 CLI 自己的模型选择，不是某个具体模型名。能连上不代表所有模型都可选用。

### 常用智能体

**GitHub Copilot**  
快捷入口会预填登录方式 `copilot-login`。请先在所选环境用官方 CLI 完成登录。已有安装也可在高级区填写 `copilot --acp`。Copilot CLI 1.0.89 实测不会提供模型列表，界面不会凭空生成。

**Gemini CLI**  
快捷入口预填 Google 登录 `oauth-personal`。请先在所选环境完成官方登录。用 API Key 时把登录方式改为 `gemini-api-key`，并在环境或实例的敏感变量里配置 `GEMINI_API_KEY`，不要写进启动命令。通用默认名 `login` 不适用于 Gemini。开启共享网关不会自动把 Gemini 接到 OpenAI/Anthropic 渠道，请按该 CLI 实际支持的登录与端点设置。

**Qwen Code**  
快捷入口或列表搜索均可；登录方式预填 `openai`。在所选环境或实例敏感变量中配置 `OPENAI_API_KEY`，并按模型服务设置 `OPENAI_BASE_URL` 与 `OPENAI_MODEL`。列表固定版本 0.24.7 需要 Node.js 22+。需要逐次批准工具时，请同时核对智能体模式与 Code Work 权限；Qwen 自身的自动模式可能直接执行工具。

**Cline**  
登录方式预填为空，使用目标环境上 `cline auth` 已保存的登录或 `CLINE_API_KEY`。可按官方配置设置 `CLINE_PROVIDER` 与 `CLINE_MODEL`。空登录只省略交互步骤，缺凭据仍无法建会话。需要显式登录时可填 `cline`、`cline-pass` 或 `openai-codex`。使用 OpenAI 兼容服务时 `CLINE_PROVIDER` 填 `openai-compatible`；3.0.65 请用 `CLINE_DATA_DIR` 指定独立数据目录。

### 实例设置分区

与 Codex / ZCode 类似，实例卡分为：

- **连接**：官方 CLI 登录提示，或开启共享网关并选择模型服务来源。
- **安装与启动**：启动命令摘要与登录方式；可从列表重新选择智能体以回填默认项。
- **高级**：完整启动命令、是否注入 Code Work MCP 工具等。

主要字段含义：

- **启动命令**：例如 `npx -y cline@3.0.46 --acp`。
- **登录方式**：建立会话时使用的方法名，默认 `login`；主动清空后保存为空，改用 CLI 已有登录或环境凭据。
- **注入 Code Work MCP 工具**：默认开启；若智能体拒绝 MCP，可关闭。Factory Droid 列表默认关闭。
- **通过共享模型网关路由**（可选）：向智能体注入标准 OpenAI / Anthropic 端点变量。只有读取这些变量的智能体才会走共享线路。

Windows 可填写已安装的 `.cmd` / `.bat`，或 PATH 中的命令；含空格时请加双引号。命令能启动不表示已经登录。

在线列表暂时不可用时，仍可搜索程序内置快照（会提示日期可能过期）。手工命令入口始终可用。使用 npx 前请安装 [Node.js](https://nodejs.org/en/download)，使用 uvx 前请安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)。

### 聊天里的模型与 `/` 命令

会话建立后，若智能体提供命令列表，在输入框输入 `/` 即可查看；选择后可补充参数再发送。模型菜单会随会话更新；上游撤回的选项不再显示，手工自定义模型仍保留。能看到模型名不表示登录或调用已经成功。

若提供会话模式，可在模型参数菜单（手机为会话设置）中选择 **Agent 模式**。Copilot 还可选择自定义 Agent 角色与 **Allow All**；保持 Off 且 Code Work 权限为受监督时，工具会按请求审批。

智能体返回的链接、图片与常见音频会按现有聊天能力展示；中间结果可能收在“工作了…”记录中。停止会话不会删除聊天历史。

### 其它列表条目与平台提示

列表会标出可安装 / 需手工配置，以及与该条命令匹配的实例状态。选择 Auggie、Factory Droid、fast-agent 等时会带上公开环境默认值；换条目会替换这些参数。CodeWhale、Gajae Code、Hermes、Kiro CLI、TRAE CLI 等多为手工安装：先按「安装说明」在服务器装好并登录，再使用预填命令。

- **Hermes**：先 `hermes model`，再用 `hermes acp`；登录方式留空。Windows 工具可能需要 Git Bash（`HERMES_GIT_BASH_PATH`）。
- **Kiro CLI**：Windows 官方包目前主要为 x64 / Windows 11；ARM64 可能显示平台不可用。
- **Gajae Code**：命令 `gjc acp`，登录方式 `agent`；Windows 命令工具需要可用 Bash。

## 助手音频与文件

智能体返回的常见音频（如 WAV、MP3、OGG、WebM、AAC、FLAC）会保存到当前环境，网页端可直接播放，移动端可通过附件入口打开；嵌入的二进制资源可下载，可执行或可脚本化类型会被拒绝。音频与二进制同样最多 10 MiB，且只接受内联数据。思考流里的音频和二进制不公开显示。

## 窄屏聊天顶栏

Web 和桌面的聊天区域较窄时，顶栏会将项目、线程标题与操作按钮分行显示。打开右侧面板后也按聊天区域实际宽度调整。

## 版本与兼容备注

- **Gemini CLI 0.61.0**：恢复会话可能丢失可恢复历史；应用会在恢复前报错并保留原历史。请改用已验证支持恢复的版本。
- **Copilot 1.0.89**：自定义模型端点时登录方式留空；命令结果若同时含“已完成”与非零退出码，按结构化退出码显示失败。
- **Factory Droid 0.229.0**：需要有效 Factory 认证；列表默认关闭 MCP 注入是兼容设置。
- **Mistral Vibe / Kilo / CodeBuddy**：自定义 OpenAI 兼容端点时，把配置与凭据放在所选服务器的实例环境中；可用性以实际会话为准。
